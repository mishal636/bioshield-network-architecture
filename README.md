# bioshield-network-architecture
A 10-week Blue Team lab architecting a secure enterprise healthcare network in Cisco Packet Tracer. Designed with 6 isolated VLANs for EHR data segmentation, a Zone-Based Firewall (ZBF), and strict ACLs. Features an IPsec Site-to-Site VPN for remote branch connectivity and a WPA2-PSK (AES) wireless deployment to ensure operational security.
